| Boundary | Description |
|----------|-------------|
| phone → POST /sessions/:id/takeover\|resume | bearer-authed request that would spawn a second writer on a transcript |
| installer → ~/.claude/settings.json | shared config with Even Terminal |
| transcript files → alerts | content written by other processes |

| T-05-09 | Denial of Service | install.sh | mitigate | settings.json untouched unless `--global-hooks` |
| T-05-10 | Information Disclosure | refusal logs | mitigate | log only `<what> <id8> <code>` |
