## Hub v1.1 API contracts (implemented for real in 05-03/05-04/05-05; the mock MUST match exactly)

GET /health (no bearer) → `{ok, protocol:1, version, gitSha, uptime, os, hubName, epoch, claude:{ok,version}, push:"ready"|"unconfigured", pushLastError: null | {status:int, reason:string, message:string, at:ISO}}`

POST /pair/auto (no bearer; tailnet listener only) body `{deviceName}` → 201 `{token, deviceId}` | 403 `{error:"forbidden"|"no_owner"|"auto_pair_denied"}` | 429 `{error:"rate_limited"}`
POST /pair body `{code, deviceName}` → 201 `{token, deviceId}` | 403 `{error:"bad_code"}`

GET /sessions → `{epoch, sessions:[{id, cwd, pid, state, source:"hub"|"external", startedAt, label?, title?, summary:string, noise:bool, lastActivity:ISO|null, entrypoint?:string}]}`

GET /sessions/:id/history?before=<int>&limit=<1..500, default 200> → `{id, lines:[{i:int, role:"user"|"assistant", text, tool?:string}], before:int|null}` (lines ascending by i; `before` = cursor for the next older page, null when at start) | 404 `{error:"not_found"}`

POST /sessions/:id/takeover | /resume → 200 `{ok:true, id}` | 409 `{error:"even_terminal"|"live_elsewhere"|"busy"|"not_resumable"}` | 404 | 400 `{error:"bad_cwd"}`
POST /sessions/:id/stop → 200 `{ok:true}`
POST /devices/push body `{token, env}` → 200; POST /devices/push/test → 200 `{sent, results:[{token, status, reason?, message?}]}` | 503 `{error:"push_unconfigured"}` | 404 `{error:"no_token"}`

WS /sessions/:id/stream?since=&epoch= → frames `{v:1,type:"hello",id,epoch,seq,state}`, events `{v:1,seq,kind:"chat",role,text,tool?,i}` / `{v:1,seq,kind:"state",state}` / `{v:1,seq,kind:"term",data:base64}`; client frames `{type:"input",text}`, `{type:"keys",data}`, `{type:"interrupt"}`, `{type:"resize",cols,rows}`. Unknown session → close 4404.
All non-health/non-pair routes require `Authorization: Bearer <token>` → 401 otherwise.
