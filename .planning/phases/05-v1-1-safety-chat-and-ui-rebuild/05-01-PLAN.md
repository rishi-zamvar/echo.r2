<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sessions.json → kill() | Persisted PIDs from a previous boot are untrusted (PID reuse) |
| hub → OS processes | Signals sent by the hub cross into processes owned by other tools (Even Terminal) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Denial of Service | Sessions boot sweep | mitigate | require exact session id in `ps` command AND non-Even-Terminal parent; fail closed on any ps error |
| T-05-02 | Information Disclosure | kill log lines | mitigate | log only pid + 8-char id + reason, never the command line (may contain prompts) |
| T-05-03 | Denial of Service | Sessions.stop | mitigate | `#killOwned` refuses PIDs not in the in-memory `#spawned` set |
| T-05-04 | Tampering | safety-harness | accept | runs only on temp dirs and its own children; no network listeners beyond loopback port 0 |
</threat_model>
