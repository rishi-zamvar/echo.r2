<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> hub (tailnet, plain http) | Bearer token and pairing code cross WireGuard tunnel; hub whois + token gate |
| app storage | Token at rest on the phone |
| user input -> URL | Host field builds request URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information disclosure | Keychain.swift | mitigate | Token only in Keychain with kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly (no iCloud sync, no UserDefaults) |
| T-03-02 | Information disclosure | HubClient request helper | mitigate | Token only in Authorization header, never in URL/query; no print/os_log of requests or headers (grep gate) |
| T-03-03 | Tampering/Spoofing | ATS config in project.yml | mitigate | Scoped NSAllowsLocalNetworking + ts.net exception only; no NSAllowsArbitraryLoads; transport confidentiality from Tailscale WireGuard (D-08) |
| T-03-04 | Tampering | Host TextField -> URL | mitigate | HubClient.baseURL(from:) rejects schemes, paths, spaces, bad ports (unit-tested) |
| T-03-05 | Elevation | 403 forbidden handling | mitigate | forbidden does not wipe the token or retry pairing; 401 wipes token and routes to Pairing |
| T-03-06 | Spoofing | Pair code brute force | transfer | Hub burns a code after 5 wrong tries, 5 min TTL (hub/auth.js) |
| T-03-SC | Tampering | SwiftPM SwiftTerm | mitigate | Single package, URL locked by D-02, legitimacy audited in RESEARCH (not npm/pip/cargo; no slopcheck gate); pinned minor version |
</threat_model>
