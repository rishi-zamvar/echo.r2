## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> hub POST /sessions | User-chosen cwd and prompt reach a process spawner on the hub |
| hub -> app GET /sessions | Hub-provided strings rendered in UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Elevation | POST /sessions cwd | transfer | Hub enforces cwd allowlist (02-03, bad_cwd); app only offers paths from /sessions/roots |
| T-03-08 | Denial of service | Prompt size | mitigate | NewSessionView caps prompt at 10000 chars (hub also 413/400) |
| T-03-09 | Information disclosure | Polling while backgrounded | mitigate | Polling bound to view .task lifetime; cancelled on disappear/background (D-13) |
| T-03-10 | Spoofing | 401 handling | mitigate | AppModel.handle(.unauthorized) wipes Keychain token and routes to Pairing |
| T-03-11 | Tampering | Hub-provided label/title | accept | Rendered as plain SwiftUI Text (no markup/links); single trusted hub |
</threat_model>
