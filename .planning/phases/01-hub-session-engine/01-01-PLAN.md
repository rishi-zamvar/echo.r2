## Phase Goal

**As a** solo operator of the home PC hub, **I want to** start Claude Code sessions in the hub and watch, steer, interrupt, and stop them from a client that can drop and reconnect, **so that** sessions keep working without me and I always know their live state.

<objective>
Walking Skeleton: the thinnest real end-to-end path. CLI → REST `POST /sessions` → hub spawns real `claude --session-id <uuid>` in node-pty → coalesced PTY output into a seq-numbered EventLog → WS stream with `since`/`epoch` replay → CLI `attach` renders the TUI. Session record persisted to `sessions.json`.

Purpose: Proves SESS-03 (sessions outlive clients, lossless replay) and fixes the architecture every later plan builds on (see SKELETON.md).
Output: hub/ package with server.js, sessions.js, eventlog.js, store.js, cli.js, hub.test.js, fixtures.
</objective>

hub/eventlog.js
- `export class EventLog { constructor({ maxBytes = 2 * 1024 * 1024 } = {}) }`
- `append(kind, payload) -> event` where event = `{ v: 1, seq, kind, ...payload }`; `seq` assigned here only (Pitfall 5); bytes = JSON length; shift oldest while total > maxBytes.
- `get seq()` last assigned seq (0 if none); `get floor()` seq of oldest retained event (seq+1 if empty).
- `since(n) -> { reset: boolean, events: Event[] }`; reset = `n < floor - 1`; events = all retained with seq > n (all retained if reset).
- `subscribe(fn) -> unsubscribe`; fn(event) called synchronously from append.

hub/store.js
- `export function load(file, fallback)` → parsed JSON or fallback if missing/corrupt.
- `export function save(file, obj)` → writeFileSync(file + '.tmp') then renameSync; mkdir -p parent.

hub/sessions.js
- `export function scrubEnv(env)` → copy without undefined values and without keys matching /^CLAUDE/i (D-15a).
- `export function resolveClaude()` → env `ECHO_CLAUDE` if set; win32: first `.exe` line from `where.exe claude`, else `%USERPROFILE%\.local\bin\claude.exe`; posix: `command -v claude` via `execFileSync('sh', ['-c', 'command -v claude'])`. No realpath. Returns `[path]`.
- `export class Sessions { constructor({ claudeCmd, epoch, dataDir, extraArgs = () => [] , extraEnv = {} }) }`
  - `claudeCmd`: array `[file, ...prefixArgs]` (tests pass `[process.execPath, fakeClaudePath]`).
  - `selfTest() -> Promise<{ ok, version }>` (D-08): spawn `claudeCmd + ['--version']` via node-pty, collect output, ok if exit 0 within 10 s.
  - `start({ cwd, prompt }) -> session`; session = `{ id, cwd, pid, state, source: 'hub', startedAt, log: EventLog, pty, cols, rows }`.
  - `get(id)`, `list() -> plain records (no pty/log)`, `input(id, text)`, `keys(id, data)`, `resize(id, cols, rows)`, `nudge(id)`.
  - `setState(session, state)` appends `{kind:'state', state}` event and persists via store.
- Args order: `[...prefixArgs, '--session-id', id, ...extraArgs(id), ...(prompt ? [prompt] : [])]` (prompt positional, never pasted — D-15a).

hub/server.js
- `export async function startHub({ port = +env.ECHO_PORT || 8790, host = '127.0.0.1', claudeCmd = resolveClaude(), dataDir = env.ECHO_DATA_DIR || ~/.echo-hub } = {}) -> { epoch, port, sessions, close() }`; `port: 0` allowed for tests (read back `server.address().port`).
- Runs `main` only when `import.meta.url === pathToFileURL(process.argv[1]).href`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local process → hub REST/WS (127.0.0.1:8790) | Any local process can call the hub; no auth in Phase 1 (D-22) |
| hub → claude child | Hub env and argv flow into a process that can execute code |
| npm registry → hub/node_modules | Third-party code installed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | server.js bind | mitigate | listen on '127.0.0.1' only; startHub throws for any other host; grep gate for 0.0.0.0. Remote exposure (RCE-by-design) is deferred until Phase 2 adds Tailscale bind + whois + token |
| T-01-02 | Elevation of Privilege | POST /sessions | mitigate | command fixed to resolved claude; only cwd (absolute existing dir) and prompt (string ≤10000) accepted; prompt passed as one argv element (no shell); never pass --dangerously-skip-permissions |
| T-01-03 | Denial of Service | REST body / WS frames / slow clients | mitigate | 1 MB body cap (413), ws maxPayload 1 MB, bufferedAmount > 1 MB → terminate, 2 MB ring cap |
| T-01-04 | Tampering | WS client frames | mitigate | JSON parse + type whitelist (input/keys/resize), resize clamped, invalid → error frame |
| T-01-05 | Information Disclosure | logs | mitigate | never log env, headers, or prompt text; terse one-line logs |
| T-01-06 | Tampering | session id path param | mitigate | UUID regex on WS path; unknown id closes 4404 |
| T-01-SC | Tampering | npm installs | mitigate | blocking human legitimacy checkpoint (Task 1) before `npm i`; exact pins + committed lockfile |
| T-01-07 | Spoofing | local unauthenticated callers | accept | single-user machine, loopback only in Phase 1; Phase 2 adds auth before non-loopback bind |
