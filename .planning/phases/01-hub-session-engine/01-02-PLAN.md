**As a** solo operator of the home PC hub, **I want to** start Claude Code sessions in the hub and watch, steer, interrupt, and stop them from a client that can drop and reconnect, **so that** sessions keep working without me and I always know their live state.

<objective>

Purpose: SESS-02 — Rishi can see whether each session is running, waiting for him, done, exited, stopped, or external, driven by signals not screen scraping.
Output: hub/hooks.js; transition() + debounce + boot marking in sessions.js; wiring in server.js; state column in cli list.
</objective>

  - states: starting, running, waiting, done, exited, stopped, external
  - signals: 'data', 'input', 'stop', 'notification', 'exit', 'boot'

  - external: unchanged for all signals except 'boot' (unchanged too) — externals are read-only watchers
  - starting + data → running; other states + data → unchanged
  - starting|running|waiting|done + input → running
  - starting|running|waiting + stop → done
  - starting|running|done + notification → waiting
  - any non-absorbing + exit → exited
  - starting|running|waiting|done + boot → stopped

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local process → hook listener 127.0.0.1:8791 | Any local process can POST; must prove the per-boot secret |
| hub → claude child env | Secret travels only in child env ECHO_SECRET |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Spoofing | hooks.js POST /hook | mitigate | per-boot 16-byte random secret, timingSafeEqual on x-echo-secret, 403 on mismatch |
| T-01-09 | Denial of Service | hooks.js body | mitigate | 1 MB cap, respond 200 before parse, parse errors swallowed |
| T-01-10 | Tampering | hook payload | mitigate | shape validation (session_id/hook_event_name strings), agent_id/SubagentStop ignored; unknown id only creates a read-only external record |
| T-01-11 | Information Disclosure | secret | mitigate | never logged; only in child env and hub memory; hub-hooks.json holds `$ECHO_SECRET` placeholder, not the value |
| T-01-12 | Elevation of Privilege | hook listener bind | mitigate | bound '127.0.0.1' only; never exposed on the tailnet listener (Phase 2 keeps it loopback) |
</threat_model>
