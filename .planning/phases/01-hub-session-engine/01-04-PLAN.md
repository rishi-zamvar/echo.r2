**As a** solo operator of the home PC hub, **I want to** start Claude Code sessions in the hub and watch, steer, interrupt, and stop them from a client that can drop and reconnect, **so that** sessions keep working without me and I always know their live state.

<objective>
Watch-everything slice: transcripts become chat events for hub sessions, and Claude sessions started outside the hub are discovered from `~/.claude/projects/**` and shown as read-only `external` sessions with a source label and title.

Purpose: completes SESS-02's `external` state and the hub side of chat (consumed by CHAT-01..03 in Phase 3); external records are read-only (SESS-05).
Output: hub/transcript.js; Tailer wiring in sessions.js; discovery loop in server.js; external chat in cli attach.
</objective>

New hub/transcript.js:
- `export function parseLine(obj) -> Array<{role:'user'|'assistant', text, tool?}>`
  - type 'user': message.content string → [{role:'user', text}] unless it starts with '<local-command' or '<command-name>' or obj.isMeta; array content → text blocks become user text; tool_result blocks are skipped (D-20 allows skip; discretion: no badge in Phase 1).
  - type 'assistant': each content block: text → {role:'assistant', text}; tool_use → {role:'assistant', tool: name, text: `${name}: ${shortArg}`} where shortArg = first of input.command, input.file_path, input.pattern, input.description, input.prompt, else '' — truncated to 80 chars, newlines → spaces; thinking and unknown blocks dropped.
  - every other type (mode, permission-mode, attachment, system, last-prompt, ai-title, unknown) → [].
- `export class Tailer { constructor(file, onLine) ; poll() }` — byte offset + Buffer remainder; split on 0x0A in Buffer space; JSON.parse each whole line in try; truncation (size < offset) resets offset to 0. `start()` uses fs.watch(file) + 1 s setInterval poll; `stop()`.
- `export function findTranscript(projectsDir, id)` → path of `<projectsDir>/*/<id>.jsonl` via readdirSync (never reverse-encode cwd, D-06) or null.
- `export function labelFor(entrypoint)` → cli: 'Terminal', sdk-ts: 'Even Terminal/SDK', sdk-cli: 'claude -p', claude-desktop: 'Desktop', else 'Other'.
- `export function discoverExternal(projectsDir, { ownedIds, maxAgeMs = 30 * 60 * 1000, liveIds = new Set() })` → [{id, transcriptPath, cwd, label, title, mtimeMs}] for `*.jsonl` whose basename UUID is not owned AND (mtime within maxAgeMs OR id in liveIds). Reads only the first 64 KB for entrypoint/cwd and the last 64 KB for the latest ai-title (aiTitle) or last-prompt (lastPrompt) for title.
- `export function liveSessionIds(claudeHome)` → Set of sessionId from `<claudeHome>/sessions/*.json` whose pid is alive (process.kill(pid,0)); missing dir → empty Set (undocumented registry, research Pattern 7; mtime is the fallback).
- Claude home: startHub option `claudeHome = env.ECHO_CLAUDE_HOME || ~/.claude`; projectsDir = claudeHome + '/projects'.
