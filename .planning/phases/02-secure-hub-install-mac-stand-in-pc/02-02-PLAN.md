New contracts this plan creates:
- `new Pairing({ttlMs = 300000, now = Date.now})`: `create(name)` → {code, expiresAt}; replaces any live code (one live code, D-06). Code = 8 chars from alphabet `0123456789ABCDEFGHJKMNPQRSTVWXYZ` via crypto.randomInt(32). `redeem(input)` → {name} on success (deletes code: single use) or null; normalize input: uppercase, strip spaces and '-', map O→0, I→1, L→1; compare with timingSafeEqual on equal-length buffers; null if no live code or expired (expired deletes it); wrong → attempts++, at 5 delete code (D-07).
- `new Devices(file)`: loads devices.json (array of {id, name, hash, createdAt, lastSeen}); `add(name)` → {token, deviceId}: token = randomBytes(32).toString('base64url'), id = crypto.randomUUID(), stores sha256 hex only, saves with mode 0o600; `verify(token)` → device or null (sha256 then timingSafeEqual against every stored hash hex-decoded; sets lastSeen in memory, persists at most every 60 s); `revoke(idOrName)` → array of removed ids (exact id match first, else exact name; if name matches >1 throw {code:'ambiguous'}); `list()` → [{id, name, createdAt, lastSeen}] (never hash).
- Loopback routes: POST /admin/pair-code {name?} → 200 {code, expiresIn: seconds}; GET /admin/devices → {devices}; POST /admin/revoke {id} → 200 {revoked:[ids]} | 404 {error:'not_found'} | 409 {error:'ambiguous'}.
- Tailnet: POST /pair {code, deviceName} (whois required, no token) → 201 {token, deviceId} | 403 {error:'bad_code'} (same body for no code / expired / wrong — no oracle). Device name = name given to pair-code, else deviceName (string, trimmed, max 64), else 'device'.
- WS: `ws.deviceId` set on tailnet upgrades; revoke closes matching sockets with code 4401.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tailnet peer → /pair | Unauthenticated (whois-only) code redemption |
| tailnet peer → all other routes/WS | Bearer token required |
| disk → devices.json / config.json | Token hashes and owner at rest |
| local process → loopback /admin/* | Can mint codes and revoke; unauthenticated by design |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Spoofing | /pair code brute force | mitigate | 40-bit CSPRNG code, single live code, 5-min TTL, 5 wrong attempts invalidate globally, same 403 body for all failures |
| T-02-09 | Information Disclosure | devices.json | mitigate | only sha256 hex stored, file mode 0600 via store.save {mode}; 'devices file' test |
| T-02-10 | Information Disclosure | token/hash compare | mitigate | timingSafeEqual on equal-length digests; grep gate against `===` |
| T-02-11 | Spoofing | token in URL | mitigate | Bearer header only; query param ignored; 'bearer required' test |
| T-02-12 | Elevation of Privilege | revoked device with open WS | mitigate | revoke closes sockets by ws.deviceId with 4401; every HTTP request re-verifies |
| T-02-13 | Spoofing | other tailnet user pairs first | mitigate | owner captured from whois at first pair; RUNBOOK (02-04) instructs pairing right after install; later mismatches 403 |
| T-02-14 | Elevation of Privilege | loopback /admin/* | accept | single-user machine; any local process could equally spawn claude directly; browser-originated requests blocked by the 02-01 Host/Origin guard; noted in RUNBOOK |
