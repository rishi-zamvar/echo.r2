- `auth.js` `defaultTailscale()` → string[] command: `ECHO_TAILSCALE` env (single path) else darwin `/usr/local/bin/tailscale` if it exists else `/Applications/Tailscale.app/Contents/MacOS/Tailscale`; win32 `C:\Program Files\Tailscale\tailscale.exe`; else `tailscale` (D-03).

- `auth.js` `isTailnetIp(ip)` → true iff `net.isIPv4(ip)` and first octet 100 and second octet 64..127 (CGNAT 100.64.0.0/10). Production never accepts anything else. Tests bind the tailnet listener on 127.0.0.1 only via the test-only startHub option `allowLoopbackTailnet: true` (default false; never read from env or config).
- `auth.js` `makeWhois({cmd, ttlMs = 60000})` → `async whois(remoteAddress)` → LoginName string or null. Strips `::ffff:`; rejects unless `net.isIP(ip)`; execFile (no shell) with `['whois','--json', ip]`, timeout 3000, maxBuffer 1 MiB; `JSON.parse(stdout)?.UserProfile?.LoginName` or null; additionally returns null when LoginName is empty, not a string, or equals `tagged-devices` (Tailscale's placeholder for tagged nodes, D-05) — this applies even when no owner is configured yet. Caches only successful lookups per IP for ttlMs (D-21); Map cleared when size > 100. Per-instance cache (no module global).
- `auth.js` `loadConfig(dataDir)` → object from `<dataDir>/config.json` with defaults filled and persisted if anything was missing: `hookSecret` (randomBytes(16) hex), `roots` (darwin/linux: [`~/Documents/Projects`, `~`] expanded; win32: [`%USERPROFILE%\Projects`]); `owner` stays absent until first pair. `saveConfig(dataDir, cfg)` writes via store.save with mode 0o600.
- `store.save(file, obj, {mode} = {})`: when mode given, write tmp with that mode and chmodSync(tmp, mode) before rename.
- `startHub` new options: `tailscale` (string[] cmd, default `defaultTailscale()`), `tailnetPort` (default = port), `retryMs` (initial backoff, default 1000; cap 30000), `allowLoopbackTailnet` (test-only, default false). Return adds `tailnetServer` (null until bound), `tailnetReady` (Promise<number> resolving with bound tailnet port), `config`.
