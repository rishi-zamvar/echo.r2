hooks-merge contract (shared with Windows install.ps1 in 02-05 — keep exactly):
- CLI: `node hub/install/hooks-merge.js merge [settingsPath]` / `unmerge [settingsPath]`; settingsPath default `<ECHO_CLAUDE_HOME or ~/.claude>/settings.json`; port from ECHO_HOOK_PORT or 8791; secret from loadConfig(dataDir).hookSecret. Exit 0 on success, non-zero with one-line message on failure.
- URL `http://127.0.0.1:<port>/hook/ext/<hookSecret>`; entry `{type:'http', url, timeout: 3}` in a matcher group `{hooks:[entry]}` under `hooks.Stop` and `hooks.Notification`. Marker = any hook url containing `/hook/ext/`.
- `merge(settings, url)`: for each of Stop, Notification: arr = settings.hooks[event] ??= []; drop groups whose hooks contain a marked url; push the new group. Returns the same object (all other keys/order preserved).
- `unmerge(settings)`: drop marked groups; delete the event key only if the array became empty; delete settings.hooks only if it became empty AND was created by merge (simplest: only if empty).
- File I/O: missing settings.json → start from {}; unparsable JSON → exit 1 without writing; backup `settings.json.echo-bak` only if it does not exist yet (never clobber the first backup); write atomically (tmp + rename) with mode 0o600.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer → ~/.claude/settings.json | Modifies the user's global Claude config |
| installer → ~/Library/LaunchAgents | Persistent autostart of a network-facing process |
| git remote → deploy.sh | Pulled code runs with the user's privileges |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-22 | Tampering | settings.json merge | mitigate | read-modify-write whole file, backup once, abort on parse error, atomic write mode 600, only marker entries touched; 'hooks merge' tests |
| T-02-23 | Denial of Service | global hooks when hub is down | mitigate | http hooks with timeout 3, no onFailure:block (grep gate); Claude proceeds on failure |
| T-02-24 | Information Disclosure | hook secret in settings.json URL | mitigate | settings.json chmod 600 after merge; loopback-only listener; secret rotates only by deleting config.json |
| T-02-25 | Tampering | deploy.sh pulling code | accept | private repo, owner-only pushes, --ff-only refuses rewritten history |
| T-02-26 | Elevation of Privilege | LaunchAgent | mitigate | per-user agent (gui/$UID), no sudo, absolute node path, plutil -lint before bootstrap |
| T-02-27 | Repudiation | launchd.log/hub.log | accept | single-user; logs local only |
</threat_model>
