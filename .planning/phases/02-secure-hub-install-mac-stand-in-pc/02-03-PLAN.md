## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| paired phone → POST /sessions cwd | Remote-supplied path decides where Claude runs |
| any local process → 127.0.0.1:8791/hook/ext/<secret> | Global hook endpoint reachable from loopback |
| hub → hub.log on disk | Persistent log readable by the user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-17 | Information Disclosure | /sessions/roots | mitigate | token-required on tailnet; dirs only, dotfiles skipped, 200 cap |

| T-02-20 | Information Disclosure | hub.log | mitigate | no tokens/codes/headers/transcripts logged; 'no secrets in log' test; rotation caps disk use at ~10 MB |
