<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone -> hub resume/takeover routes | authed requests that spawn processes on the hub |
| hub <-> other Claude clients (Even Terminal, plain claude) | two writers on one session transcript |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Elevation | resume/takeover spawning in arbitrary dirs | mitigate | inRoots(cwd, config.roots) re-checked on both routes; ids must match the uuid regex; only known records resumable |
| T-04-14 | Tampering | two writers on one session (takeover while another client is live) | mitigate | 409 busy if transcript mtime < 60 s or liveSessionIds() has the id (D-08); app confirm sheet in 04-05 |
| T-04-15 | Spoofing | unauthenticated resume | mitigate | Routes sit behind whois + bearer on tailnet, loopback host/origin checks locally (existing makeHandler) |
| T-04-16 | Denial of service | repeated resume spawning many claudes | mitigate | Resume only from exited/stopped; running -> 409 not_resumable |
| T-04-17 | Information disclosure | env leaking to resumed claude | mitigate | Same #spawn path: scrubEnv + per-boot ECHO_SECRET only |
</threat_model>
