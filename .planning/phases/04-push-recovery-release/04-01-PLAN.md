## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone -> hub tailnet listener | push token registration crosses here (whois + bearer already enforced) |
| hub -> Apple APNs (internet) | JWT-signed HTTP/2 requests leave the machine |
| disk (~/.echo-hub) | .p8 signing key and device tokens at rest |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information disclosure | .p8 key file | mitigate | Read only from ~/.echo-hub (outside repo); chmod 600 on load if wider; never logged; config only stores keyPath |
| T-04-02 | Spoofing | POST /devices/push | mitigate | Route sits behind whois + bearer; token bound to dev.id from bearerDevice, never from the body |
| T-04-03 | Tampering | push token input | mitigate | Hex regex 64..200, env enum, body capped by MAX_BODY |
| T-04-04 | Information disclosure | push payload | mitigate | Title <= 60, body <= 140, first line only; no transcript beyond that line |
| T-04-05 | Information disclosure | logs / admin devices list | mitigate | Logs show token first 8 chars only; list() exposes push: boolean, never the token |
| T-04-06 | Elevation | revoked device keeps receiving pushes | mitigate | Token lives on the device record; revoke deletes the record (tested) |
| T-04-07 | Denial of service | /devices/push/test spam | accept | Only the paired owner can call it; APNs throttles; single user |
| T-04-08 | Repudiation | stale token deletion | accept | Deletion logged with reason; app re-registers on next launch |
</threat_model>
